## 二、P1 问题清单与原因分析

### P1-01 空库注入演示数据

- 现象：空数据库仍显示演示文档；删除最后一篇后演示数据重新出现。
- 位置：`src/renderer/src/stores/document.ts`。
- 根因：`initialize()` 在 `stored.length === 0` 时赋值为 `DEMO_DOCUMENTS`，并将 `DEFAULT_DOCUMENT` 当作真实文档。
- 影响：真实空状态不可达，数据与 UI 假象不一致。

### P1-02 数据模型缺少分类和日志

- 现象：分类、日志入口只有界面，没有持久化能力。
- 位置：`src/shared/document.ts`、`src/main/documentRepository.ts`。
- 根因：数据库仅定义 `schemaVersion: 1` 和 `documents`；`DocumentRecord` 无 `categoryId`，也没有 Category/Journal 类型、接口或 IPC。
- 影响：无法完成真实新增分类、新建日志及分类筛选。

### P1-03 损坏或未知数据库被静默当作空库

- 现象：数据库内容损坏或版本不识别的潜在风险被掩盖为空集合。
- 位置：主进程和浏览器 fallback 仓储。
- 根因：解析失败、schema 不匹配或结构不合法时返回空数据。
- 影响：用户可能误以为数据丢失，后续写入还可能覆盖原文件。

### P1-04 新建文档/分类/日志入口无业务逻辑

- 现象：资源栏“新建文件夹”“新建文档”和文档头部“+”只有图标；日志无页面。
- 位置：`ResourceSidebar.vue`、`DocumentHeader.vue`、`DocumentEditorPage.vue`。
- 根因：按钮没有 click handler，Store/API/Repository 也没有对应 create 方法。
- 影响：核心新增功能不可用。

### P1-05 菜单和浮层不完整

- 现象：部分菜单按钮无响应；“查看更多”、最近文档更多、面包屑加号、更多、标签按钮、工具区搜索/通知/账户等只有 UI。
- 位置：资源栏、文档头部、编辑器工作区。
- 根因：事件未绑定，或状态变量（如 `settingsOpen`、`fontMenuOpen`）未参与模板；缺少外部点击/Esc 关闭逻辑。
- 影响：用户看到可点击外观但没有真实行为。

### P1-06 导航并非页面切换

- 现象：首页、知识库、日志、AI、设置只更新本地高亮。
- 位置：`NavigationRail.vue`、`DocumentEditorPage.vue`。
- 根因：`activeItem` 位于组件内部，未进入共享 Store，也没有页面状态。
- 影响：日志新增和视图切换不可达；AI/设置的真实能力尚未实现。

### P1-07 分类、计数、时间、同步状态和今日记录为硬编码

- 现象：分类计数、子分类、最近文档更新时间、同步状态、“今日已记录 +1”固定，不随数据库变化。
- 位置：`ResourceSidebar.vue`、`NavigationRail.vue`。
- 根因：模板中直接写死演示值，未从真实 Store 计算。
- 影响：UI 展示与真实数据不一致，属于演示假象。

### P1-08 交互与保存反馈存在伪成功风险

- 现象：分享复制失败仍显示“分享信息已准备好”；收藏只改变本地 `ref(true)`，不持久化。
- 位置：`DocumentHeader.vue`、`EditorWorkspace.vue`。
- 根因：无持久化字段/API，失败分支仍给出正向反馈。
- 影响：用户误以为操作成功。未实现能力应明确禁用或准确提示。

### P1-09 IPC 参数校验不足

- 现象：保存 payload 只检查少数字段，未校验 categoryId、tags 元素、revision/version 非负整数和 Tiptap 文档结构。
- 位置：`src/main/ipc.ts`。
- 根因：边界校验不完整。
- 影响：非法渲染进程数据可能进入数据库。
